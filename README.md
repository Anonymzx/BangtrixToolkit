# Bangtrix Translate Universal

Custom node for ComfyUI.

## Features

* Auto Translate (Google)
* Multi-language support
* Positive & Negative output
* Direct CLIP conditioning
* Quality preset (normal, high, ultra)
* Style preset (anime, realistic, cinematic, etc)
* Auto Negative system
* Cache & Offline fallback

## Installation

1. Go to:
   ComfyUI/custom_nodes/

2. Clone repository:
   git clone https://github.com/USERNAME/BangtrixTranslateUniversal.git

3. Restart ComfyUI

## Usage

Connect:

* positive_conditioning → KSampler Positive
* negative_conditioning → KSampler Negative
